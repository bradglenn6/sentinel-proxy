# Security Policy

## Supported Versions
Currently, only the latest release of ZeroLabz Sentinel is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability, prompt injection bypass, or zero-day evasion technique within Sentinel, please DO NOT report it in the public issue tracker. 

Instead, please email the details directly to **dev@zrolabz.com**. 

We take all security reports seriously and will acknowledge your email within 48 hours to coordinate a patch and responsible disclosure timeline.
